Mine Bitcoin by Hand

This is an educational page meant to show exactly what a Bitcoin miner is upto. Unfortunately, if you guess the magic nonce, this is not actually hooked up to the network.

A. Become a full node

The Bitcoin network is made up of thousands of computers all around the world running software that implements the Bitcoin protocol. The job of these computers is to listen for new transactions and blocks, verify them against the blockchain, and relay them to the rest of the network. A block is a history of recent transactions, roughly the last 10 minutes worth. The blockchain is a record of all past bitcoin transactions. A computer that does this is called a Full Node.
    Requirements of a Full Node
  • Online 24/7
  • Listen for new transactions and blocks
  • Verify transactions and blocks against the blockchain
  • Relay valid transactions and blocks to the rest of the network (Peer-to-peer)

B. Prepare next block

A "miner" is a person who uses their computers to not only run a Full Node, but also tries to validate the next block.

Gather recent transactions

  1. Gather recent, valid transactions, usually favoring those with the highest transaction fee.(Mempool)
  2. Add a transaction that awards transaction feeds to the miner, as well as newly minted Bitcoin as per the award protocol
  3. Organize transactions into a Merkle tree to compute the Merkle Root.

Gather information about the next block, this is called the Block Header

  • Version of bitcoin protocol
  • Previous block hash
  • Merkle Root
  • Timestamp
  • Record of current Difficulty called Bits
  • A number used only once, called a Nonce

C. Try, try again

  1. Compute the hash of the block header
  2. Compare hash to the target.
  3. If hash is less than the target, YOU WIN! Send the new block to peers.
  4. If not, increment the Nonce and try again!
